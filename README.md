**القرآن الكريم مع التفسير — بدون إنترنت**

# القرآن الكريم — تطبيق أندرويد (مصحف المدينة، ٦٠٤ صفحة)

تطبيق أندرويد يعرض **صور المصحف الشريف**، مع إمكانية **البحث** في الآيات الكريمة والكلمات، وعرض **التفسير في نفس الشاشة** أسفل صفحة المصحف، على غرار تطبيق «قرآن أندرويد».

يعمل التطبيق **بدون اتصال بالإنترنت بالكامل**.

## المميزات

- **تصفح صفحات المصحف:** تقليب الصفحات بالسحب من اليسار إلى اليمين، مثل المصحف الورقي، مع حفظ آخر صفحة تم الوصول إليها وفتحها تلقائيًا عند تشغيل التطبيق مرة أخرى.
- **لوحة التفسير:** تظهر أسفل صفحة المصحف، وتتضمن:
  - عرض الآيات الموجودة في الصفحة على شكل شرائح.
  - إمكانية اختيار آية ثم اختيار التفسير المطلوب.
  - عرض شرح الآية مباشرة.
  - أزرار «الآية السابقة» و«الآية التالية»، مع إمكانية الانتقال بين الصفحات والسور.
  - إمكانية تكبير وتصغير حجم الخط.
  - إمكانية تكبير لوحة التفسير.
- **البحث:** إمكانية البحث باستخدام:
  - كلمة أو جملة، دون الحاجة إلى التشكيل.
  - تجاهل اختلافات الهمزات والتاء المربوطة أثناء البحث.
  - مرجع الآية، مثل `٢:٢٥٥` أو `البقرة ٢٥٥`.
  - رقم صفحة المصحف.
- **الفهرس:** يحتوي على السور الـ١١٤ والأجزاء الـ٣٠.
