# القرآن الكريم — تطبيق أندرويد (مصحف المدينة ٦٠٤ صفحة)

تطبيق يعرض **صور المصحف** اللي رفعتها، مع **بحث** في الآيات والكلمات، و**تفسير في نفس الشاشة** تحت الصفحة (على غرار «قرآن أندرويد»). يشتغل **بدون إنترنت** بالكامل.

## المميزات
- تقليب الصفحات بالسحب (من الشمال لليمين زي المصحف)، ويفتح على آخر صفحة وقفت عندها.
- **لوحة التفسير** تحت الصفحة: شرائح بآيات الصفحة ← اختر آية ← اختر التفسير ← يظهر الشرح فورًا. أزرار «السابقة/التالية» (تعدّي حدود الصفحات والسور)، تكبير/تصغير الخط، وتكبير اللوحة.
- **البحث**: بكلمة أو جملة (من غير تشكيل، ويتجاهل اختلاف الهمزات والتاء المربوطة)، أو بمرجع مثل `٢:٢٥٥` أو `البقرة ٢٥٥`، أو برقم صفحة. بحث «متسامح» بيلاقي كلمات الرسم العثماني زي *إبراهيم* و*يؤمنون*.
- **الفهرس**: ١١٤ سورة و٣٠ جزء.

## التفاسير
| مدمجة في التطبيق | إضافية (في `extra_packs/`) |
|---|---|
| الميسر، الجلالين، السعدي، الوسيط (طنطاوي)، ابن كثير | البغوي، القرطبي، الطبري |

**لإضافة تفسير:** انسخ ملف `tafsir_<اسم>.db` لأي من:
1. `app/src/main/assets/tafsir/` قبل البناء (يزيد حجم الـ APK)، أو
2. جهاز الأندرويد في `Android/data/com.quranreader/files/tafsir/` (بعد تشغيل التطبيق مرة) — من غير إعادة بناء، وهيظهر تلقائيًا.

(مصدر التفاسير: مشروع `spa5k/tafsir_api` على GitHub، ونص القرآن من حزمة `quran-json`، والصفحات/الأجزاء من `quran-meta` برواية حفص.)

## البناء
**الطريقة ١ — Android Studio (الأسهل):** افتح مجلد المشروع ← انتظر Sync ← Run ▶ على جهازك، أو `Build > Build APK(s)`.
المتطلبات: Android Studio حديث (Koala أو أحدث) + JDK 17 (مرفق معه).

**الطريقة ٢ — من غير Android Studio:** ارفع المشروع على GitHub وشغّل `Actions > Build APK` (الملف `.github/workflows/build-apk.yml`) ونزّل `app-debug.apk`.

الحد الأدنى للأندرويد: ٧.٠ (API 24).

## هيكل المشروع
```
app/src/main/assets/pages/      ٦٠٤ صورة (1.png … 604.png)
app/src/main/assets/db/         quran.db  (الآيات + الصفحات + نص البحث)
app/src/main/assets/tafsir/     tafsir_<key>.db
app/src/main/java/com/quranreader/
   data/   QuranRepo (قواعد البيانات)، Normalizer (تطبيع البحث)
   ui/     ReaderScreen، TafsirPanel، SearchScreen، IndexScreen
tools/build_data.py             يعيد توليد قواعد البيانات من المصادر
```
> لو عدّلت `Normalizer.kt` لازم تعدّل `normalize()` في `tools/build_data.py` بنفس الشكل وتعيد توليد `quran.db`.
