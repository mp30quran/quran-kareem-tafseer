# القرآن الكريم — تطبيق أندرويد (مصحف المدينة ٦٠٤ صفحة)

تطبيق يعرض **صور المصحف الشريف** ، مع **بحث** في الآيات الكريمة والكلمات، و**تفسير في نفس الشاشة** تحت الصفحة (على غرار «قرآن أندرويد»). يشتغل **بدون إنترنت** بالكامل.

## المميزات
- تقليب الصفحات بالسحب (من الشمال لليمين زي المصحف)، ويفتح على آخر صفحة وقفت عندها.
- **لوحة التفسير** تحت الصفحة: شرائح بآيات الصفحة ← اختر آية ← اختر التفسير ← يظهر الشرح فورًا. أزرار «السابقة/التالية» (تعدّي حدود الصفحات والسور)، تكبير/تصغير الخط، وتكبير اللوحة.
- **البحث**: بكلمة أو جملة (من غير تشكيل، ويتجاهل اختلاف الهمزات والتاء المربوطة)، أو بمرجع مثل `٢:٢٥٥` أو `البقرة ٢٥٥`، أو برقم صفحة. بحث*.
- **الفهرس**: ١١٤ سورة و٣٠ جزء.
